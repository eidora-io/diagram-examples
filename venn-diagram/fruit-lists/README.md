# Three Lists: Red, Sweet and Round Fruits

![Three-circle Venn diagram example made from three lists of fruits: red, sweet and round, with apple and cherry in all three](preview.webp)

Three lists (red, sweet and round fruits) sorted into all seven regions, with apple and cherry in the middle. Every item sits in exactly one place. A quick check for classification exercises.

## Input text

```text
Which fruits are red, which are sweet, which are round?
Red: apple, cherry, strawberry, tomato, raspberry
Sweet: apple, cherry, strawberry, banana, mango, grape
Round: apple, cherry, tomato, orange, grape, blueberry
```
