# Hospital Management System ER Diagram

![Hospital management system ER diagram example: departments, doctors, patients, appointments, prescriptions, rooms and admissions](preview.webp)

A hospital model with departments, doctors, patients, appointments, prescriptions, rooms and admissions. Appointments and admissions are entities because each carries its own dates. Use it for clinic-booking or patient-records designs.

## Input text

```text
Hospital management system: each doctor works in one department. Patients book appointments with doctors; an appointment has a date, a time and a reason. A doctor can write prescriptions at an appointment. Patients can be admitted to a ward room, with an admission date and a discharge date. Each room belongs to one department.
```
