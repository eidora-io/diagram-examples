# Digestive System Concept Map From Notes

![Digestive system concept map example made from a student's notes: mouth, esophagus, stomach, small intestine and large intestine, with what each contains and does](preview.webp)

A concept map made from a student's own biology notes, following food from the mouth to the large intestine. Each organ lists what it contains and what it does, and links tie food, starch and proteins to nutrients. It shows how study notes can become a map.

## Input text

```text
My biology notes: Digestion starts in the mouth, where teeth break food down and saliva contains amylase, which breaks down starch. The esophagus moves food to the stomach. The stomach uses acid and pepsin to break down proteins. Most nutrients are absorbed in the small intestine through villi. The large intestine absorbs water.
```
