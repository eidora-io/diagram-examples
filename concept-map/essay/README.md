# Essay Plan Concept Map

![Essay plan concept map example on social media and teenagers: heavy use linked to anxiety and poor sleep, encouraged by algorithms and reduced by limits set by parents and schools](preview.webp)

An essay plan turned into a concept map: heavy social-media use in the centre, with what leads to it, what it is linked to and what can reduce it. Each arrow can become a paragraph. Use it to find gaps in an argument before writing.

## Input text

```text
Concept map for my essay on social media and teenagers: social media increases connection with friends, but heavy use is linked to anxiety and poor sleep. Algorithms keep teens scrolling. Parents and schools can set limits.
```

The same text is in [source.txt](source.txt). Made with the [Concept Map Maker](https://www.eidora.io/tools/concept-map-maker).
