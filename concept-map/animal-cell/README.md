# Animal Cell Concept Map

![Animal cell concept map example: the cell membrane, cytoplasm, nucleus and organelles, with the nucleolus producing ribosomes](preview.webp)

A structure map of the animal cell, with each organelle under the group it belongs to. Cross-links add function, such as the nucleolus producing ribosomes and mitochondria releasing energy. Useful for cell-biology revision.
