# Company Org Chart From a List

![Hierarchical company org chart made from an indented list: a CEO, two vice presidents with their teams, and an HR manager](preview.webp)

A hierarchical org chart made from an indented list of names and titles: CEO, vice presidents, managers and teams. Pasting a list copied from a spreadsheet or an HR system is enough. It shows how indentation becomes reporting lines.

## Input text

```text
CEO - Jane Doe
  VP Sales - Mark Ellis
    Sales Manager East - Ann Lee
    Sales Manager West - Bob Kim
  VP Engineering - Linus Berg
    Backend team: 4 engineers
    Frontend team: 3 engineers
  HR Manager - Grace Hall
```
